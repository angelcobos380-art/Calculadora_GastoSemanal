
# Gasto Semanal

## Descripción
Aplicación para registrar y gestionar los gastos semanales de forma sencilla y organizada.

## Características
- Registrar nuevos gastos
- Categorizar gastos por tipo
- Ver total de gastos semanales
- Interfaz intuitiva y responsiva
- Almacenamiento local de datos

## Tecnologías
- HTML5
- CSS3
- JavaScript (ES6+)

## Uso
1. Ingresa la descripción del gasto
2. Selecciona la categoría
3. Ingresa la cantidad
4. Haz clic en "Agregar gasto"
5. Visualiza el resumen semanal
