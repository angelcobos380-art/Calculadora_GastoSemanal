## Descripción del proyecto

Esta aplicación permite controlar un presupuesto semanal y registrar cada gasto de manera rápida, clara y práctica. El usuario puede establecer un monto inicial, añadir gastos con su descripción y valor, y ver en tiempo real cuánto dinero le queda disponible.

El proyecto está pensado para resolver un problema cotidiano: llevar el control del dinero sin complicaciones. Además, ayuda a identificar cuándo el presupuesto está siendo consumido demasiado rápido y a tomar decisiones más conscientes.

## ¿Qué hace esta app?

- Define un presupuesto semanal desde el inicio
- Registra gastos con nombre y cantidad
- Muestra el total gastado y el dinero restante
- Alerta cuando el presupuesto está llegando a niveles críticos
- Permite eliminar gastos si se necesita corregir un registro
- Bloquea nuevas operaciones cuando ya no queda presupuesto disponible

## Funcionalidades principales

- Formulario para ingresar gastos con validación de datos
- Cálculo automático del presupuesto restante
- Actualización dinámica del contenido en la interfaz
- Mensajes de alerta para errores y confirmaciones
- Indicadores visuales de estado del presupuesto
- Diseño simple, limpio y fácil de usar
- Organización del código con clases en JavaScript (ej. una clase para modelar cada gasto y otra para controlar la lógica del presupuesto), aplicando principios básicos de programación orientada a objetos

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript ES6+
- DOM manipulation
- Programación orientada a objetos
